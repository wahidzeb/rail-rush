About Rail Rush

Rail Rush is a gentle train puzzle. Colourful trains come out of a tunnel, and you tap the switches so each one reaches the station of the same colour.

Each switch has an arrow, and the track it points to glows. Stars depend on how many trains go to the wrong station. Later levels add more stations and switches, rainbow trains and a Slow-Mo Whistle, across 4 worlds with 8 engines.

3 quick tips

  1. Trains follow the glowing track, never the dark one, so check every switch.
  2. Set all the switches on a train's path before it arrives, starting from the one nearest the train.
  3. No mistakes means 3 stars, and every star adds a 10-coin bonus.
